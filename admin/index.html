用你的 GitHub 账号登录，即可管理日记与照片。

进入写作后台 ↗
  1. 首次登录时，授权 Pages CMS 访问 zczali4403.github.io，然后选择这个仓库的 main 分支。
  2. 打开「日记与文章」，新建文章，填写标题、日期和正文。
  3. 点击编辑器中的图片按钮，上传照片或从「日记图片」中选图。
  4. 保存后等待自动发布完成，再到博客查看。文章和图片都保存在你自己的 GitHub 仓库中。

保存即提交到公开仓库，请只保存准备公开的内容。首次授权只需选择这个网页仓库。
